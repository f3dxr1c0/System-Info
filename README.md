# System Info

A simple Python CLI system information tool.

## Features
- Display system information (user, hostname, IP, OS, Python version, current path, number of files)
- Save information to JSON files
- Log all actions in a log file
- Colored CLI interface
- Cross-platform: Windows, Linux, Mac

## Requirements
- Python 3.8 or higher
- Modules:
  - pystyle
  - colorama
